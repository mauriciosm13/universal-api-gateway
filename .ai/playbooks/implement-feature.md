# Implement Feature Playbook

1. Read [PROJECT_BIBLE.md](../../docs/PROJECT_BIBLE.md) and relevant RFC/ADR.
2. Write or update the Spec using [templates/SPEC.md](../../docs/templates/SPEC.md).
3. Implement in `internal/` following hexagonal boundaries.
4. Add tests (`go test ./...`).
5. Update docs and [CHANGELOG.md](../../CHANGELOG.md).
6. Open PR using [pull-request checklist](../checklists/pull-request.md).
